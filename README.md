# Chatbot Application README

## Overview
This application is a chatbot built using React for the front end and leveraging both the Gemini and OpenAI APIs for generating responses. It provides a user interface for interacting with AI models, allowing users to send messages and receive AI-generated replies.

## Features
- **Dual API Support:** Utilizes both Google Gemini and OpenAI APIs for diverse and robust AI responses.
- **React-based UI:** A responsive and intuitive user interface built with React.
- **Real-time Chat:** Enables real-time interaction with the AI models.
- **API Key Management:** Securely handles API keys for both Gemini and OpenAI.
- **Message History:** Displays a history of sent and received messages.
## Technologies Used
- React
- JavaScript
- Google Gemini API
- OpenAI API
- CSS
- Vite (or similar build tool)
